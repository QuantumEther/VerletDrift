# Experiment 05 — initial multi-RPM prototype (partially validated)

Open `engine-sim-hybrid-v5.html` through HTTP/HTTPS alongside the supplied recordings. The five audio modes retain the previous interface. All previous pages and vehicle physics remain untouched.

`engine-v5-recording-analysis.json` records decoded duration, channels, RMS, peak and prominent spectral components. All seven new files are stereo 48 kHz, approximately 5.96–9.62 s. The first 2000 take has RMS .0124 versus .2012 for take 2 (~24 dB difference). Their strongest components are both near 66 Hz; louder does not establish superior quality. Take 2 is provisionally selected, without a listening verdict. The decoded 7000 recording peaks above nominal full scale (about 1.26 in mono analysis); this requires attenuation but does not by itself prove the source has hard clipping. The other anchors show increasing prominent components consistent with filename ordering, but combustion fundamental, cylinder count and actual RPM are not verified.

The prototype decodes each anchor once, trims 0.6 s from the start and 0.3 s from the end, removes mean offset, and applies a 120 ms circular raised-cosine overlap. These are provisional loop regions, not optimized or independently auditioned seams. Each loop is normalized to fixed RMS .012. Native buffer sources remain continuously running, with 40 ms playback-rate and 60 ms gain smoothing. Adjacent anchors use complementary linear weights: this avoids assuming uncorrelated sources for equal-power gain, but does NOT solve phase cancellation or beating. No phase lock or crank synchronization is implemented. Only two anchors have substantial target gain at once; no source restarts on anchor crossings.

Between 1200 and 2000 rpm, the selected previous recording blends into the new anchors. Compatibility of these unknown-engine recordings is not established; this low-RPM transition needs listening evaluation. Above 7000, the final anchor continues with a modest rate increase rather than being muted. Missing anchors are excluded and reported; if all fail, the prior recording remains available. The filename RPM is used as a provisional pitch anchor, not a measured calibration.

Multi-RPM Sample silences procedural output. Multi-RPM Hybrid retains the prior high-pass procedural detail mix and component controls. Background MP3 bed and recorded rev excerpts default to zero for this experiment. Throttle/load shaping remains the prior approximate model; no new measured load model is claimed.

Verification: inline JavaScript syntax checks passed. `node research/scientific-rebuild/fast-vehicle-poc/variable-terrain/engine-sim-multirpm-test.mjs` passed Chromium startup, six-anchor loading, recording switches and inherited transient/isolation checks. This is NOT a complete Mission 05 validation. Unfinished items include calibrated periodicity/stability analysis, neighbor spectral consistency, phase-aware crossing tests, slow/fast sweeps and boundary holds, missing/corrupt-file tests, all-five-mode signal measurements, limiter/aliasing studies, long-duration performance and perceptual evaluation. The current test inherits checks from Experiment 04 and does not independently establish multi-anchor acoustic quality.

Do not interpret this prototype as meeting the naturalness success criterion. The most important next step is a controlled anchor-boundary listening/signal test, with phase alignment or a different blend method only if the measured interference warrants it.
