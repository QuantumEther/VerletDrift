# Timestep audit: current production chain

Engine throttle lag uses exp(-h/tau); starter angle and work use h. Engine firing thresholds are angular speeds; extinction delay accumulates seconds. Pressure plate uses backward-Euler coefficients in h and reports command work/heat/loss. Gearbox selector force is in N; selector coordinates integrate with h. Rotor inverse inertia retains drivetrain coupling. Clutch/brake/friction bounds are h times torque/force capacity; compliance is 1/(h*stiffness). Steering damping uses inertia+h*damping; steering position uses h*angularVelocity. Terrain positions use q1=q0+h*v1; suspension damping work uses h and the discrete conservative work uses actual endpoint displacement. Endpoint thresholds are absolute physical/work errors, unchanged across h. Defaults `h=.001` are fallback API arguments, not forced values when the clock supplies h.

Inherited `gearbox.js:recordImpact` divides impact impulses by .001 to display reference averaged force/torque. Physical velocity jumps use impulses, not those displayed averages. The displayed impact force is therefore a 1 ms reference average, not a force averaged over a selectable step. Original source is preserved; Experiment 11 now explicitly labels the 1 ms impact reference in its UI; historical implementations remain unchanged. Non-flat selector crossings continue to reject, rather than silently missing events.

Tracks accumulate force-times-slip-times-h work and use world-distance sampling/deposition. Recording gap/jump thresholds are observational continuity rules, not tire-force laws. Camera interpolation uses a per-render fraction; this is presentation, not mechanical motion. Flat terrain deliberately retains the original Experiment 10 integration and gear-event path.

Clock accounting now passes the chosen h, advances simulated time only on acceptance and reports the correct h-times-steps throughput. Switching discards pending debt into the existing explicit wall-time counter and clears rate windows. Rejected step latency is now recorded even when there was no previously accepted step. No reference masses, stiffnesses, damping constants, energy tolerances or iteration limits were changed.
