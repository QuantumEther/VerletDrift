# Experiment 11 development — incomplete

Only the deterministic shared terrain sampler is implemented. It supplies height, analytic gradient/unit normal, material/friction and a graded road corridor with smooth shoulders. Supported reference ranges are amplitude 0–0.5 m and roughness 0–1. Friction values are illustrative, not measured tire calibration. Three tests verify flat equivalence at the sampler level, seed replay, analytic gradients against finite differences, normalized normals and corridor continuity. This does NOT establish solver-level flat equivalence or terrain driving.

The next operation is an Experiment-11-specific extension of Experiment 10's combined solver: construct each local contact frame at its actual wheel/world position, map normal and tangent Jacobians into all relevant generalized velocities, and include the normal force's horizontal reactions and work. Supplying only height offsets to the vertical model would omit gravity-driven slope motion and violate the requested physical coupling. After inclined-plane/one-wheel and energy/refinement tests pass, adapt the inherited application and road/track mesh to this same sampler. There is no standalone interactive entry point or registry entry yet; Experiment 11 is not available to drive and the mission is not complete. Experiments 1–10 are unchanged.

`src/contact-frame.js` constructs terrain-aligned longitudinal, lateral and normal rows for the inherited 18-velocity ordering. It projects the wheel-forward direction into the tangent plane and maps reaction forces through the same rows as velocities; wheel spin enters only longitudinal slip. Two additional tests verify exact flat row reduction, normalized/orthogonal slope directions and virtual work for every velocity coordinate. This is a production integration primitive, not an enabled second contact solver. It is not yet connected to the vehicle update loop: the next required operation is to replace flat normal spring reactions with terrain-frame reactions and consistent elastic contact work, and feed those rows into the single combined solve. Until then there is no drivable terrain page or navigator release.
