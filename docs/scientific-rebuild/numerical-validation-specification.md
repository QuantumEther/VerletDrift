# Numerical validation specification — no implementation

## Candidate and independent reference

Candidate: fixed-step classical explicit RK4 on the unchanged five-state RHS, constant gamma/Md, h={1/100,1/200,1/400,1/800} s. These are candidates to compare, not accepted stable rates. Default implementation starting point would be 800 Hz for the restricted envelope, but no rate earns acceptance without the tests below. Do not add recursive contact refinement, switch models at low speed or silently accept failed steps.

Two algebraic tire force/moment calls per derivative evaluation, four stages → **eight constitutive calls per attempted RK4 step**. Stage state remains immutable while evaluating both axles. Cost includes failed stages separately; offline equilibrium search/Jacobian/diagnostic calls must not be reported as per-step constitutive work. Optional pose/work quadrature reuses existing stage forces; separately counted verification samples are not secretly omitted.

Independent offline reference: DOP853 adaptive eighth-order method, maximum step 1/6400 s, relative tolerance 1e-12 and absolute tolerances 1e-4 times the state allowances below. Repeat with max step 1/12800, rtol=2.5e-13 and quartered atol. Reference agreement must be <=0.01 of every state allowance at common times. Otherwise reference is **UNRESOLVED**; a candidate cannot pass against it. This offline adaptive reference is not a real-time recursive tire solver. The governing function remains the same piecewise explicit constitutive law; use an independent transcription/cross-check of force equations so agreement does not merely replicate one typo. High precision point checks supplement, not replace, independent integration.

## Error budget and units

These are declared research comparison requirements, not universal accuracy constants or tire calibration uncertainty. Goal: distinguish millimetre-scale ordinary trajectory differences over 5 s and short-time perturbations of at least 0.01 m/s /0.001 rad/s without integrator error dominating them.

Set component absolute error allowances A=[1e-4 m/s,1e-4 m/s,1e-6 rad/s,1e-3 rad/s,1e-3 rad/s]. Normalize `e=max_i |x_i-xref_i|/A_i`; require e<=1 over each complete declared horizon. If velocity error stayed at its allowance, direct displacement error over 5 s is <=0.5 mm/component. A yaw-rate error of 1e-6 rad/s would accumulate <=5e-6 rad heading error; at 25 m/s its position contribution is approximately <=0.313 mm over 5 s. These are explanatory first-order bounds; pose quadrature is checked directly if used, not certified by the bounds alone. Rotor allowance corresponds to 0.0003 m/s peripheral speed. Model/calibration error is separate and may be vastly larger.

For perturbations use the same state normalization but report physical units too. The budgets are comfortably below the manifest perturbations; if instability amplifies error beyond them, shorten only under the predeclared diagnostic policy, or classify the long-horizon comparison unresolved/failing. Do not relax accuracy until a trajectory “passes.”

Energy/work closure requirement: absolute residual <=0.001 J over up to 5 s and decreasing under refinement, with reference uncertainty <=0.00001 J. This is an engineering diagnostic target chosen to distinguish work on the order of a millijoule while not mistaking the ~0.231 W analytical counterexample for quadrature error. It is not a tolerated positive physical energy creation rate. A candidate unable to meet it is not validated for energy analysis at that step; increase refinement or report failure, not a larger hidden tolerance. Pointwise power checks use roundoff-aware units/scales separately.

## Stiffness, branches and acceptance of a method

Near rolling, Kx=2a²kx=80000 N per slip and approximate frozen-chassis rotor decay magnitude is 1600/v per second (Mission 14 derivation). At the rotor cutoff peripheral speed 6 m/s, the nominal product h|lambda| is 2.667 at 100 Hz and 0.333 at 800 Hz. This motivates a finer candidate, but coupled body modes, mu0>mu negative force slopes, drift instability and branch transitions are not bounded by this scalar calculation. Stable decay of a scalar test equation is not proof of nonlinear RK4 stability.

Compare state errors on identical physical grids, maximum-in-time as well as endpoint; report successive error ratios and observed order log2(E_h/E_h/2). For equilibria where roundoff dominates, do not infer order from tiny differences. Report smooth adhesive/sliding intervals separately from branch crossings. Eq.(20) is branchwise analytic; branch boundary matching does not establish fourth-order global convergence, especially with input/domain events. DOP853 also requires refinement there. If 800 Hz fails, do not claim all fixed-step methods are inadequate; report the failed candidate and require a separately reviewed numerical decision. No new algorithm is authorized by the failure.

Track K-Kcrit, minimum Omega/load margin and each axle's branch at every stage; report crossing brackets and refinement shifts. Domain policy rejects invalid stages, so the last endpoint is not an exact continuous exit time. No endpoint interpolation across a rejected step can restore a passing result. Offline event localization, if used, is explicitly labeled and compared under refinement.

## Reproducible measurements and criteria

Outcome vocabulary: **PASS** meets the named claim; **FAIL** contradicts it; **OUT OF DOMAIN** is a declared boundary crossing; **UNRESOLVED** lacks sufficient precision/evidence. Source fidelity and physical passivity are different claims. In this documentation mission all unperformed trajectory/benchmark tests remain UNRESOLVED. Analytical established outcomes are listed below.

|Requirement|Measure and procedure|Acceptance / invalidation / remaining uncertainty|
|---|---|---|
|Dimensions|Hand-check Eq.(7)/(20), Delta, loads, torque and work using SI|PASS analytical; invalid units invalidate transcription. No empirical fidelity implied.|
|Pure/combined slip|Point fixtures and symmetric sign transforms at manifest loads; compute physical slips from motion independently|Published Eq.(20), static/sliding magnitudes and direction must agree within accumulated roundoff. A friction envelope alone is not enough. Real tire fit still unknown.|
|Branch matching|Compare lambda→0 from adhesion with saturated side; include exact threshold and decreasing offsets|Fx/Fy approach mu Fz times slip direction and Mz→0; source continuity PASS analytically. Derivative smoothness/order still needs tests.|
|Zero slip|Exact S=0 extension plus directional small-slip sequences|Exactly zero forces/moment at zero; slopes tend to 2a²kx,2a²ky and moment slope -(2/3)a³ky. No epsilon dead zone. Analytical limit PASS.|
|Symmetry|Mirror sigma,omega,gamma; recompute full trajectories and observables|Symmetry is analytical; future roundoff/state deviations must remain below the error budget and scale like roundoff for paired RHS. Physical asymmetry not inserted.|
|Order independence|Evaluate front/rear from the same stage in reversed call order|Same derivatives to arithmetic roundoff, no mutation. Trajectories/replay must be reproducible in the fixed environment; no guarantee across arbitrary JS/libm platforms.|

|Replay|Exact config, unrounded root, tick/input order, same numeric environment, fresh state|Bitwise repeat within the declared environment excluding timers; platform differences reported rather than mislabeled nondeterminism.|
|Convergence|Candidate vs independently refined reference on common physical times|Component errors <=allowances and systematic reduction until roundoff/reference floor; unexplained qualitative changes invalidate the rate. No universal global fourth-order claim.|

|High sideslip|Refine drift seed, measure residual/Jacobian/slips and short perturbations|Countersteered high-slip branch and convergent unstable short-time response; instability itself is expected, not FAIL. Leaving domain → OUT OF DOMAIN.|

|CPU cost|Warmup, repeated matched cases, distribution and metadata below|Measured evidence only; benchmark unperformed here. Speed does not override any accuracy/domain failure.|

For pointwise algebra/sign tests bound arithmetic error with a conservative 512*binary64_epsilon times a unit-bearing operation scale, using sums of absolute work terms for powers, mu0 Fz for force and a mu0 Fz for moments. Verify borderline cases with higher precision rather than increasing this factor. Units-scaled absolute floors must be documented if introduced; a single dimensionless epsilon cannot replace all units. At exact zero use exact limiting returns. The counterexample's positive work is orders of magnitude above these bounds.

## Work quadrature and benchmark plan

At every stage compute Md Omega_r, each Pforce and omega Mz, and energy-gradient/RHS residual. Accumulate signed work with RK4 weights, compensated sums, and record positive/negative contact work separately. Compare delta E to the **full signed sum**, not to drive minus a presumed positive heat quantity. A positive contact-work region can coexist with an exactly closed ledger. Also compare against independent reference quadrature; do not fit the ledger from delta E by definition.

For future CPU tests name CPU/OS/runtime/browser version, power mode, precision, step, workload, compiler settings and source/config hash. Warm up 10000 RHS calls outside measured samples, then collect at least five serial repetitions of 10000 full steps per scenario, restoring a documented state for independent short segments if a long trajectory would leave domain. Never benchmark invalid continued trajectories; mark reset-segment timing separately from continuous timing. Report mean/median/p95/p99/worst CPU step time, tire count, allocations and GC observations; run no competing profiler. Timer overhead and instrumentation must be measured separately. No performance number or universal timing acceptance is assigned before target hardware/real-time use is agreed; initial scientific acceptance is bounded count and successful numerical accuracy. A later browser budget requires full application/frame/input costs, not this isolated timing.
