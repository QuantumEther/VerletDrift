# Braking experiment tire tracks

The braking experiment uses the observatory's `TireObservatory`, `tracks.js`, `track-view.js` and `contact-observation.js`. Its vehicle exposes the same optional accepted-stage observer interface: rejected event-search probes never emit records; accepted split stages are reported once. The vehicle integration and force laws are unchanged. The 2D view draws rubber, center path, individual paths and slip vectors; 3D draws bounded rubber geometry. Controls independently toggle recording and visibility, and Clear Tracks removes recorded geometry. Reset breaks continuity and retains existing marks, as in the observatory; clearing explicitly removes them. Switching views does not reset history. The braking experiment exposes recording controls directly rather than reproducing the separate observatory's friction-circle panel.

Both experiments' contact observations now include the solver's projected steering-axis trail offset before transforming into world coordinates. Mark widths and visual opacity are the observatory's uncalibrated work-based deposition model; normal rolling alone is not a skid mark. Each wheel has a 1024-mark ring and a 2048-point path ring. The GPU track mesh is bounded and incrementally updated. The braking renderer explicitly disposes its track resources on recreation.

Vehicle tests compare accepted-stage states and marks against the observatory during steering and braking; tests also check zero rubber during ordinary rolling and the steered world-coordinate transform. Chromium exercised braking, view switching and clearing in both experiments. The pre-integration predecessor's index, display code and other changed sources are preserved under `research/scientific-rebuild/steering-predecessor/` and tested against the archived revision. The observatory's unchanged tire-force and steering solver remain authoritative.
