PROPOSAL 2 — HORIZONTAL CARDS One card per subsystem, side-by-side in a horizontal scroll lane. Search filters all cards simultaneously — sliders that don't match collapse, cards with zero matches dim to 40%. Spatial layout lets you compare parameters across subsystems without switching tabs. Best for: cross-subsystem comparison
▸ Pros / Cons

PROS

  • All subsystems simultaneously visible
  • Spatial memory — you learn card positions
  • Search results span every subsystem at once
  • Card height independent per subsystem

CONS

  • Horizontal scroll is unusual for control panels
  • Cards can vary widely in height — uneven
  • Narrow cards squeeze slider labels
  • Hard to see all sliders without scrolling within card
